# System Engineering & DevOps -- Web Infrastructure Design
![Nginx](https://img.shields.io/badge/Nginx-1.24-green) ![HAProxy](https://img.shields.io/badge/HAProxy-2.8-blue) ![MySQL](https://img.shields.io/badge/MySQL-8.0-orange)

This repository contains the Web Infrastructure Design projects from the System Engineering & DevOps curriculum at Holberton School. It focuses on designing scalable, secure, and highly available web architectures through whiteboard-style diagramming and conceptual planning.

## Sub-Projects

### web_infrastructure_design/

| Task | Description |
|------|-------------|
| Task 0 -- Simple Web Stack | 1 server, Nginx, application server, MySQL |
| Task 1 -- Distributed Web Infrastructure | 2 servers, HAProxy load balancer, Primary-Replica Database |
| Task 2 -- Secured and Monitored Infrastructure | Firewalls, SSL encryption, Sumo Logic monitoring |
| Task 3 -- Scale Up | Dedicated components, HAProxy cluster, no single point of failure (SPOF) |
